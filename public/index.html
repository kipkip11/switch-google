Chuyển tiếp trực tiếp luồng chat gốc của Antigravity IDE qua Switch Google với độ trễ < 5ms và giữ nguyên Native Headers.

1. Lệnh tin cậy chứng chỉ Root CA nội bộ (chạy 1 lần)
2. Lệnh chuyển hướng /etc/hosts sang Switch Google
3. Lệnh chuyển hướng cổng 443 → 8443 (macOS pfctl / Linux iptables) Bắt buộc khi ứng dụng chạy với user thường (không dùng sudo)

Tích Hợp 1-Click Vào Công Cụ Lập Trình

Sao chép nhanh cấu hình OpenAI-Compatible cho IDE, Agent hoặc kiểm thử bằng cURL.

Antigravity IDE Khuyên dùng

Cấu hình Switch Google làm Custom OpenAI Gateway để dùng trọn bộ tài khoản xoay vòng:

Provider:  OpenAI Compatible
Base URL:  http://localhost:1909/v1
API Key:   sk-switch-local
Models:    gemini-3.8-flash, gemini-4-argon, claude-3-7-sonnet
Cursor IDE OpenAI Compatible

Vào Cursor Settings > Models > Override OpenAI Base URL và điền thông số:

Base URL:  http://localhost:1909/v1
API Key:   sk-switch-local
Models:    gemini-3.8-flash, claude-3-7-sonnet
Roo-Code / Cline (VS Code) Extension

Chọn Provider "OpenAI Compatible" trong cài đặt tiện ích mở rộng:

API Base URL: http://localhost:1909/v1
API Key:      sk-switch-local
Model ID:     gemini-4-argon
CLI Coding Assistant Shell Env

Xuất biến môi trường để định tuyến công cụ dòng lệnh qua Switch Google:

export OPENAI_BASE_URL="http://localhost:1909/v1"
export OPENAI_API_KEY="sk-switch-local"
coding-agent --model gemini-3.8-flash
cURL Quick Test HTTP Test

Kiểm tra nhanh kết nối Gateway trực tiếp từ Terminal:

curl http://localhost:1909/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.8-flash","messages":[{"role":"user","content":"Hello"}]}'
